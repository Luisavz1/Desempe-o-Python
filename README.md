📚 Gestión de Estudiantes

Este programa permite registrar, consultar, actualizar y eliminar información de estudiantes usando un menú interactivo en consola.

✅ Funcionalidades

    Registrar estudiante
    Guarda el nombre, edad y tres notas de un nuevo estudiante.

    Consultar estudiante
    Busca un estudiante por su ID y muestra sus datos junto con el promedio de notas.

    Actualizar notas
    Permite modificar las tres notas de un estudiante existente.

    Eliminar estudiante
    Elimina un estudiante del sistema por su ID.

    Ver todos los estudiantes
    Lista todos los estudiantes registrados con su ID, nombre y promedio de notas.

    Salir
    Finaliza el programa.

🛠️ Requisitos

    Python 3.x

No se requieren librerías externas.

▶️ Ejecución

Guarda el código en un archivo llamado gestion_estudiantes.py y ejecútalo con:

python gestion_estudiantes.py

📌 Notas

    Las entradas se validan para evitar errores de tipo.

    El identificador de estudiante (ID) debe ser numérico, pero se guarda como cadena para facilitar la gestión.

    Las notas deben ser valores decimales (float) y se promedian automáticamente.
